# FastAPICourseLesson19

# Задание по программированию повышенной сложности:

    Это задание экспериментального уровня. Оно требует от вас самостоятельного поиска решений. Используйте документацию, пробуйте разные подходы и не бойтесь экспериментировать. Такой формат поможет вам развить навыки анализа и работы с новыми технологиями.

Расширьте предыдущее приложение FastAPI, добавив управление документацией в зависимости от режима окружения (DEV/PROD). Мы условно готовим приложение к развёртыванию в продакшене: в проде у нас вся документация API должна быть отключена, а в деве мы защищаем ссылку /docs базовой аутентификацией (чтобы туда доступ был только по логину/паролю).

1. Конфигурация окружения
Режим работы приложения определяется переменной окружения MODE (допустимые значения: DEV, PROD).
Данные для аутентификации в документации (только для DEV) хранятся в переменных окружения: DOCS_USER и DOCS_PASSWORD.

2. Защита документации в DEV-режиме
В режиме DEV:

    Эндпоинты /docs  и /openapi.json должны требовать базовую аутентификацию. Эндпоинт /redoc должен быть скрыт.

    Для проверки учетных данных используйте secrets.compare_digest() для защиты от тайминг-атак.

    При неудачной аутентификации возвращайте статус 401 с заголовком WWW-Authenticate: Basic.

    Сами эндпоинты должны быть исключены из схемы OpenAPI (include_in_schema=False).

3. Отключение документации в PROD-режиме
В режиме PROD:

    Полностью скройте эндпоинты /docs, /openapi.json, /redoc.

    При обращении к ним должен возвращаться статус 404 Not Found.

4. Реализация

    Используйте условные проверки режима при инициализации приложения.

    Для переопределения стандартных эндпоинтов документации добавьте кастомные маршруты с зависимостями (dependencies).

    Убедитесь, что в PROD-режиме схема OpenAPI не генерируется или недоступна.

5. Тестирование

DEV-режим:

curl -u valid_user:valid_password http://localhost:8000/docs

                      
                  
                  

PROD-режим:

curl http://localhost:8000/docs  # Должен вернуть 404

                      
                  
                  

Примечание:

    Для работы с переменными окружениями используйте python-dotenv, environs или pydantic-settings.

    Стандартные маршруты документации FastAPI должны быть переопределены.

    Не забудьте обработать кейс, когда переменная MODE имеет недопустимое значение


# Запуск
1. `git clone git@github.com:XDKAY/FastAPICourseLesson19.git`
2. `cd FastAPICourseLesson19`
3. `uv venv`
4. `source .venv/bin/activate`
5. `uv sync`
6. Создайтей .env файл в FastAPICourseLesson19 (пример, как должен выглядить см. .env.example)
7. `uvicorn application.main:app --reload`
8. http://127.0.0.1:8000/api/docs
